# Glossary

> **Status:** Verified (each term is defined from the code or schema named in the third column). Terms from the business domain that the code does not define are not included.

| Term | Meaning in this project | Source |
|---|---|---|
| **Bazaar** | A basket with at least `FREE_DELIVERY_MIN_ITEMS` (default 15) *different products*; ships free. The same product in two sizes counts once. | [`delivery.py`](../../backend/app/services/delivery.py), [`bazaar.py`](../../backend/app/services/bazaar.py) |
| **Bazaar+** | Customer status unlocked by `BAZAAR_PLUS_ORDERS_REQUIRED` (default 6) Bazaar orders in the current calendar month (`BAZAAR_TIMEZONE`, default `Asia/Kolkata`); cancelled/expired orders do not count. The benefit itself is not implemented in the backend beyond exposing eligibility at `GET /bazaar/status`. | [`bazaar.py`](../../backend/app/services/bazaar.py) |
| **Base fee / per-km fee** | `DELIVERY_BASE_FEE` (default 20) plus `DELIVERY_PER_KM` (default 10) × road km (capped at `DELIVERY_MAX_CHARGED_KM`, default 30), rounded up to a whole rupee. | [`delivery.py`](../../backend/app/services/delivery.py), [`config.py`](../../backend/app/core/config.py) |
| **Packing point** | The one active warehouse (`inventory_locations.is_packing_point`) from which delivery distance is measured; env `PACKING_POINT_*` is the fallback. | [`inventory.py`](../../backend/app/services/inventory.py) `set_packing_point`, [`delivery.py`](../../backend/app/services/delivery.py) |
| **Variant** | A sellable size/pack of a product (`product_variants`: name, SKU, unit, quantity). Prices attach to variants. | [`product_variant.py`](../../backend/app/models/product_variant.py) |
| **Stock pool** | The shared physical stock of all same-unit-family sizes of one product (e.g. 250 g and 1 kg draw from the same kilograms). | [`stock_pool.py`](../../backend/app/services/stock_pool.py) |
| **Reserve level** | Quantity of a variant to keep back from sale (`product_variants.reserve_level`); drives low-stock alerts. | [`stock_alerts.py`](../../backend/app/services/stock_alerts.py) |
| **Batch** | A received supply (from a supplier or farm) that lots belong to. | [`batch.py`](../../backend/app/models/batch.py) |
| **Lot** | Quantity of one variant from one batch at one location (`inventory_lots`); has `quantity` and `reserved_quantity`. | [`inventory_lot.py`](../../backend/app/models/inventory_lot.py) |
| **Stock movement** | Append-only record of a quantity change on a lot (`RECEIPT`, `ADJUSTMENT_IN/OUT`, `DAMAGE`, `WASTE`, `TRANSFER_IN/OUT`, `DISPATCH`). | [`stock_movement.py`](../../backend/app/models/stock_movement.py) |
| **Reservation** | Stock held for an order (`inventory_reservations` + per-lot allocation rows). `ACTIVE → COMMITTED / RELEASED / EXPIRED`; window 30 minutes. | [`inventory_reservation.py`](../../backend/app/services/inventory_reservation.py), [`reservation_state.py`](../../backend/app/services/reservation_state.py) |
| **Sweep** | Background loop in `main.py` that expires overdue reservations every 120 s (one `asyncio` task per process). | [`main.py`](../../backend/app/main.py) |
| **Fulfillment** | Warehouse-to-door progress of an order (`PENDING → PICKING → PACKED → READY_FOR_DELIVERY → ASSIGNED → OUT_FOR_DELIVERY → DELIVERED`). | [`fulfillment_state.py`](../../backend/app/services/fulfillment_state.py) |
| **COD** | Cash on Delivery. Payment stays `PENDING` until the delivery partner confirms delivery, which records the cash as collected. | [`payment.py`](../../backend/app/services/payment.py) `_confirm_cod`, [`fulfillment.py`](../../backend/app/services/fulfillment.py) `_collect_cod_payment` |
| **UPI (payment method)** | The stored `payments.payment_method` value for *every* online (Razorpay) payment, whatever instrument the customer used. The DB check allows only `UPI` and `COD`. | [`payment.py` model](../../backend/app/models/payment.py) |
| **Pay-first checkout / checkout session** | Online flow where the order is created only after Razorpay confirms the payment; `checkout_sessions` remembers the priced cart and the Razorpay order. | [`checkout_session.py`](../../backend/app/services/checkout_session.py) |
| **Payment transaction** | One gateway attempt (`PAYMENT` or `REFUND`) under a payment; unique `idempotency_key`. | [`payment_transaction.py`](../../backend/app/models/payment_transaction.py) |
| **Webhook event** | Deduplicated record of a gateway callback, unique on `(gateway_name, event_id)`. | [`payment_webhook_event.py`](../../backend/app/models/payment_webhook_event.py) |
| **Refund (approval lifecycle)** | `PENDING_APPROVAL → APPROVED → PROCESSING → REFUNDED` (or `REJECTED` / `FAILED`); created automatically only for cancelled orders whose online payment reached `PAID`. | [`refund_state.py`](../../backend/app/services/refund_state.py) |
| **Promotion / offer** | A promotion is a discount rule; an *offer* is a promotion with `show_in_carousel` on that is currently redeemable. | [`promotion.py`](../../backend/app/services/promotion.py), [`offers.py`](../../backend/app/services/offers.py) |
| **Effective status (promotion)** | Time-derived `SCHEDULED/ACTIVE/EXPIRED` computed from the stored admin status plus `starts_at/ends_at`; never stored. | [`promotion_state.py`](../../backend/app/services/promotion_state.py) |
| **Bulk request / quote / quote version** | Wholesale flow: customer request → admin quote (versions are immutable once sent) → customer accepts → admin converts to an order. | [`bulk_order.py`](../../backend/app/services/bulk_order.py) |
| **Firebase ID token** | Short-lived JWT issued by Firebase after sign-in; sent as `Authorization: Bearer`. Verified by the backend; never trusted for roles. | [`firebase.py`](../../backend/app/core/firebase.py) |
| **Sync (`POST /auth/sync`)** | Call after every Firebase sign-in that finds, links or creates the application `users` row. | [`services/auth.py`](../../backend/app/services/auth.py) |
| **Legacy migration** | One-time move of a pre-Firebase account (password hash in `users.password_hash`) into Firebase; erases the hash. | [`services/auth.py`](../../backend/app/services/auth.py) `migrate_legacy_account` |
| **Role / permission** | Role = row in `roles` linked through `user_roles` (read live each request). Permission = string in the static `ROLE_PERMISSIONS` map in code. | [`permissions.py`](../../backend/app/core/permissions.py) |
| **Staff roles** | `ADMIN, HUB_STAFF, OPERATIONS, DELIVERY_PARTNER, SUPPORT`. | [`roles.py`](../../backend/app/core/roles.py) |
| **Authz golden matrix** | Reviewed snapshot of which role reaches which operation; the test fails if any route's access changes without updating it. | [`tests/authz_golden.json`](../../backend/tests/authz_golden.json), [`tests/test_authz_matrix.py`](../../backend/tests/test_authz_matrix.py) |
| **Disposable test database** | A local PostgreSQL carrying the comment `gb-disposable-test-db`, named `*_test`, that the suite may TRUNCATE. | [`tests/_db_safety.py`](../../backend/tests/_db_safety.py) |
| **`xfail(strict=True)`** | A test that encodes a *known, unfixed* defect; it fails the suite the moment the defect is fixed, forcing the marker to be removed. | [`test_money_integrity.py`](../../backend/tests/test_money_integrity.py), [DEFECT_LOG](../testing/DEFECT_LOG.md) |
| **EAS / OTA update** | Expo Application Services build and over-the-air JavaScript update; the app listens on the channel baked into the build (`preview` or `production`). | [`mobile/eas.json`](../../mobile/eas.json), [`mobile/app.json`](../../mobile/app.json) |
